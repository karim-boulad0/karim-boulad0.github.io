Overview

Markazi Fruits is an online grocery store built around fresh fruit and vegetables. Customers shop through a bilingual storefront and an Android app, while the team behind the scenes runs the operation from a single admin dashboard.

The project spans two very different front ends — a customer-facing catalogue in Arabic and English, and a dense back office for the people packing and dispatching orders. Both are served by the same Laravel REST API, so an order placed on the website and an order placed on a phone land in the same queue with the same statuses.

  • Bilingual (Arabic / English) storefront with categories, brands, search, wishlist, and seasonal campaigns.
  • Order management covering phone, Android, iOS, and website orders.
  • Delivery timeslots and service locations used to schedule fulfilment.
  • Promotions, banners, promo codes, and win-back campaigns managed from the dashboard.
  • Financial and operational reporting alongside a CMS and application logs.

My role

I worked on the backend and the admin experience: modelling the commerce data, exposing it through REST endpoints, and building the screens the operations team uses every day.

  • Developed Laravel API modules for orders, products, categories, users, offers, promo codes, timeslots, and locations.
  • Built responsive React.js admin screens for order handling, catalogue management, and reporting.
  • Designed the MySQL schema around a high volume of daily orders and the queries the dashboard depends on.
  • Implemented promotion and retention tooling, including banner scheduling, promo codes, and win-back campaigns.
  • Exposed a single API contract shared by the storefront, the admin dashboard, and the mobile app.

Key features

Bilingual storefront

An Arabic and English catalogue with product categories, brand partners, search, wishlist, and seasonal deals.

Order operations

A high-volume order queue with platform and status filters, order detail views, and staff assignment.

Delivery timeslots

Configurable delivery windows tied to service locations so orders are grouped into workable routes.

Promotions & retention

Banners, offers, promo codes, and win-back campaigns controlled from one place without a deployment.

Customer segments

Platform-based segments and the Markazi Elite tier, so repeat customers can be recognised and rewarded.

Reporting & CMS

Revenue and order charts, monthly completion breakdowns, report exports, CMS pages, and application logs.

Tech stack

The stack was chosen for fast iteration, a clean API boundary, and straightforward hosting on standard PHP infrastructure.

  • Laravel
  • PHP
  • React.js
  • JavaScript (ES6+)
  • MySQL
  • REST API
  • Payments
  • Git

Architecture: an API-first Laravel backend shared by the storefront, the React.js admin dashboard, and the Android app, with a MySQL schema tuned for a high volume of daily orders.

Outcome

Markazi Fruits runs its online grocery operation from a single system: customers order from the website or the Android app, and every order, customer, promotion, and delivery window is visible to the team in one dashboard.

Because the storefront and the back office share the same API, new campaigns and catalogue changes ship without touching the customer experience — and the platform is still live and in daily use.
