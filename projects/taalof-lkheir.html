Overview

Taalof Lkheir is a business management platform built to bring a company's public presence and its internal operations into the same ecosystem. The public website gives the business a clear online entry point, while the admin dashboard handles the work behind the scenes: inventory, field sales, and accounting.

The project was delivered inside the Paratune / Al-Raqia product environment, where the goal was a single, role-based system instead of a collection of disconnected tools. The backend exposes a Laravel REST API; the admin experience is a responsive React.js dashboard that talks to that API.

  • Public website for the company's online presence.
  • Central inventory management across items, stock, and movement records.
  • Field-sales workflows supported by mobile-facing API endpoints.
  • Accounting modules with project revenue, payables, and profit & loss reporting.

My role

I worked across the stack — from database structure and API design to the interfaces the operations team uses every day.

  • Designed and implemented Laravel backend modules and RESTful endpoints for the dashboard and mobile-facing workflows.
  • Built responsive React.js admin screens connected to the API.
  • Modeled inventory, sales, and accounting data in MySQL with attention to query performance.
  • Implemented role-based access so each team member sees only the modules they need.
  • Shipped the public landing page and kept the admin experience visually consistent with it.

Tech stack

The stack was chosen for fast iteration, a clean API boundary, and straightforward hosting on standard PHP infrastructure.

  • Laravel
  • PHP
  • React.js
  • JavaScript (ES6+)
  • MySQL
  • REST API
  • Git

Architecture: an API-first Laravel backend with a React.js admin client, a relational MySQL schema, and a separate responsive public website.

Outcome

Taalof Lkheir brought the company's public presence and day-to-day operations into one connected system: a public website, a central admin dashboard, and a Laravel API that keeps inventory, field sales, and accounting data in sync.

The modular API foundation leaves room for additional mobile clients and future operational modules without reworking the core.
