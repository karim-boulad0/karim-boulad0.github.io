Overview

Hayah Calm — حياة مستقرة — is a telehealth platform built around one promise: help yourself from the comfort of your home, easily, conveniently, and with complete privacy. Instead of travelling to a clinic, a client opens the site, picks a specialty, finds a specialist, and books a video session.

The platform covers psychological counselling, family and marital therapy, behaviour modification, special education, speech and language therapy, physical therapy, and student guidance — so different needs land in the right place instead of one generic "therapy" bucket. Behind the public site sit two dashboards: one for specialists and one for the admin team running the marketplace.

  • Seven specialties, from psychological counselling to speech and physical therapy.
  • A specialist directory with profiles, years of experience, and direct booking.
  • Client and specialist accounts with their own login and dashboard.
  • Single sessions and multi-session packages, sold and tracked as orders.
  • An admin dashboard for revenue, orders, clients, specialists, packages, and blogs.
  • A mobile app on Google Play, Arabic-first with an English option.

My role

I built the platform end to end — the public website, the booking and order flow, the client and specialist accounts, the admin dashboard, and the API that also powers the mobile app.

  • Built Laravel REST endpoints for specialties, specialists, packages, orders, sessions, blogs, and site content.
  • Implemented the public site: specialties grid, specialist profiles, store, blogs, and the "start now" entry point.
  • Built client and specialist authentication with role-based redirects, password reset, and social sign-in.
  • Modelled the order lifecycle — pending, confirmed, paid, completed, and cancelled — with packages, promo codes, payments, ratings, and testimonials.
  • Built the admin dashboard covering revenue, orders by status, clients, specialists, packages, blogs, and editable site content.
  • Connected the mobile app to the same API, including the Arabic/English language choice.

Key features

Tech stack

One API serves the website, the admin dashboard, and the mobile app — so content, prices, and availability are entered once and appear everywhere.

  • Laravel
  • PHP
  • MySQL
  • REST API
  • JavaScript (ES6+)
  • Payments
  • Role-based access control
  • Git

Architecture: a Laravel backend with role-scoped endpoints for clients, specialists, and admins; a MySQL schema built around specialties, specialists, packages, orders, and sessions; and a content layer that lets the admin team edit the site and publish blog posts without a deploy.

Outcome

Hayah Calm launched as a complete service: 25 active specialists across seven specialties, 68 packages on sale, 151 clients, and 56 published blog posts — all visible from one admin dashboard, alongside revenue, orders by status, and the newest specialists joining the team.

The mobile app is live on Google Play with 100+ downloads, offering the same experience in Arabic or English. For a client, the whole journey happens from home: choose a specialty, pick a specialist, book, and meet — privately.
